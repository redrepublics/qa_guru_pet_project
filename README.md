## 📌 О проекте

**QA Guru Pet Project** — учебный проект по автоматизации тестирования программного обеспечения на Python, разработанный в рамках обучения в школе [QA.GURU](https://qa.guru/).

Основная цель проекта — получить практический опыт автоматизации тестирования, научиться создавать поддерживаемые автотесты, применять инструменты Python-разработки и использовать современные подходы к обеспечению качества программного обеспечения.

Проект развивается постепенно: от изучения основ Python до реализации полноценных сценариев автоматизированного тестирования.

## 🎯 Цели проекта

- Освоить Python для задач автоматизации тестирования.
- Научиться проектировать и писать автотесты.
- Изучить инструменты и библиотеки для QA Automation.
- Получить практический опыт работы с Git и GitHub.
- Научиться организовывать структуру проекта и поддерживать читаемость кода.
- Закрепить знания на практических заданиях.

## 🚀 Запуск проекта

Клонировать репозиторий:

```bash
git clone https://github.com/redrepublics/qa_guru_pet_project.git
```

Перейти в директорию проекта:

```bash
cd qa_guru_pet_project
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать виртуальное окружение в Windows:

```bash
.venv\Scripts\activate
```
